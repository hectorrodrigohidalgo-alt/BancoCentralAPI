## Historia

Como responsable del producto, quiero evaluar si el stack del MVP permite exportar datos a Excel, para conocer sus limitaciones y los cambios que requeriría.

## Criterios de aceptación

- [x] Dado el stack elegido, cuando revise la evaluación, entonces entenderé qué trabajo adicional requiere ofrecer descargas de datos en Excel.
- [x] Dada la necesidad de exportar a Excel, cuando revise la propuesta, entonces dispondré de una recomendación justificada sobre qué mantener en el MVP y qué incorporar después, incluyendo costos y limitaciones.

Evaluación y recomendación final: [USOS-DATOS.md](USOS-DATOS.md). La verificación es documental; no se implementaron descargas.

## Plan

- Identificar las necesidades de datos para exportaciones.
- Evaluar opciones para generar Excel, considerando datos faltantes y cobertura histórica.
- Comparar mantener el stack actual frente a incorporar herramientas para exportar.
- Documentar la recomendación que apruebes.

## Fuera de alcance

- Implementar descargas o almacenamiento.
- Evaluar o implementar entrenamiento de modelos y pronósticos: descartado por el usuario.
- Incorporar otros usos futuros todavía no definidos.
